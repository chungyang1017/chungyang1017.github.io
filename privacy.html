Enix Privacy Policy

Enix is a personal assistant that Chung-Yang Yeh built for his own use. It is not offered to the public.

Enix accesses Gmail, Google Calendar, Google Drive, Docs, Sheets, and Slides only for the owner's own accounts. It uses this access only to carry out requests that the owner sends through LINE.

Data from Google is processed through Anthropic's Claude API. It is not sold, not shared with any other party, and not used for advertising.

Authorization tokens are stored as encrypted secrets on Cloudflare. They never appear in conversations.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The owner can revoke access at any time at https://myaccount.google.com/permissions.

Enix 隱私權政策

Enix 是葉崇揚為自己建置的私人助理，不對外提供服務。

Enix 只存取擁有者本人帳號的 Gmail、Google 日曆、雲端硬碟、文件、試算表和簡報。這些存取只用來執行擁有者透過 LINE 交代的事。

來自 Google 的資料經由 Anthropic 的 Claude API 處理。這些資料不出售、不提供給其他第三方，也不用於廣告。

授權憑證以加密形式存放在 Cloudflare，不會出現在對話中。

使用 Google API 取得的資訊，遵守《Google API 服務使用者資料政策》，包括其中的「有限使用」規定。

擁有者可以隨時在 https://myaccount.google.com/permissions 撤銷授權。
